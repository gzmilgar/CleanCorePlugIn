Service Binding Configuration
=============================

Name:               ZUI_I_SALESORDER_O4
Service Definition:  ZUI_I_SALESORDER
Binding Type:        OData V4 - UI
Description:         RAP Service

Note: Service Binding is created via the ADT wizard.
Steps:
  1. Right-click the package -> New -> Other ABAP Repository Object
  2. Search for 'Service Binding'
  3. Enter the name: ZUI_I_SALESORDER_O4
  4. Select Service Definition: ZUI_I_SALESORDER
  5. Choose Binding Type: OData V4 - UI
  6. Click 'Finish' and then 'Activate'
  7. Click 'Publish' to make the service available
